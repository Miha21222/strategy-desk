# Что нового в версиях

Новое сверху. Тот же список показывает приложение: Настройки → Справка → «Что нового в версиях».

## 0.2.1 — 13.10.2026

- **Обновления внутри приложения.** Настройки → Справка: кнопка «Проверить обновления», скачивание с полосой прогресса, «Установить и перезапустить». Когда на GitHub выходит новый релиз, приложение само показывает плашку под вкладками — проверку можно выключить галочкой «Проверять обновления автоматически».
- **Раздел «Справка» в настройках.** Версия, кнопки «Сообщить об ошибке» и «Веб-сайт», этот список изменений.
- **Инструкция внутри приложения.** Вкладка «Помощь» показывает ту же инструкцию, что лежит на главной странице GitHub: как читать обзоры, что нажимать утром, днём и вечером, что делать, если что-то не работает, с картинками.
- **Гайд с картинками на главной странице GitHub.** README репозитория — это инструкция для трейдера: установка шаг за шагом, скриншоты и анимации.
- 0.2.0 и раньше не умеют обновляться сами: 0.2.1 — последняя версия, которую нужно скачать руками со страницы релизов. Дальше приложение обновляется само.

## 0.2.0 — 13.10.2026

- **Текст обзоров пишется по-человечески.** В папку данных добавлен скилл `humanizer`: простые слова, одна мысль на фразу, факторы словами, а не кодами, урок в две-три фразы, ярлыки вроде «чипы» и «кэш» расшифрованы. Скилл `macro-review` прогоняет через это каждое поле вердикта, обсуждения и итога дня перед записью.
- **Обзор за выбранный день.** Кнопки обзора и довода передают скиллу дату дня на экране, поэтому повторный обзор за понедельник больше не записывается как вторник.
- Версия шаблона папки данных — 2. У кого папка уже есть: новые файлы скилла доливаются при повторном «Создать здесь» в мастере или диагностике, существующие файлы не трогаются.
- Состав установщика тот же, что в 0.1.0: Claude Code, Python + tvmcp, шаблон папки данных; базы знаний курса нет.

## 0.1.0 — 12.10.2026

- **Первый установщик.** Макро-ревью перед Европой и Америкой и итог дня — как настольное приложение для другого трейдера. Windows x64, установка для текущего пользователя, без прав администратора.
- **Всё внутри.** Claude Code, Python + tvmcp (окружение собирается при первом запуске, около 600 МБ в AppData), шаблон папки данных со скиллом `macro-review`. Отдельно ставить ничего не нужно. TradingView Desktop установщик проверяет сам и при необходимости ставит через winget.
- **Мастер первого запуска из шести страниц:** папка данных → вход в Claude → Python/tvmcp → TradingView и порт → cookie `sessionid` → расписание (три задачи планировщика, пн–пт 09:30 / 16:00 / 20:00 по Киеву). Всё, что уже есть на компьютере, второй раз не ставится. Та же проверка — в Настройках → «Диагностика».
- **Что нужно от пользователя.** Подписка Claude (Pro/Max), аккаунт TradingView (cookie `sessionid` для баров и календаря), Windows 10/11 x64, интернет при первом запуске.
- Установщик не подписан: SmartScreen покажет «неизвестный издатель» — «Подробнее» → «Выполнить в любом случае».
