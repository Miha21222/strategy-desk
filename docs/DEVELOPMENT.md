# Strategy Desk — техническое описание

Инструкция для трейдера (установка, что нажимать утром, днём и вечером, с картинками) — [README.md](../README.md) в корне репозитория. Здесь — устройство, сборка и запуск из исходников.

Настольное приложение-оболочка для чата с Claude поверх нашего MCP-сервера
`tradingview` (tvmcp). Копилот видит ваш график в TradingView Desktop через
порт отладки (CDP), может сделать скриншот, прочитать индикаторы и рисунки,
запустить сканы SMC/ICT и бэктесты — всё внутри одного окна, на русском.

Открытый код, без телеметрии, без платных стен, без своего аккаунта:
используется ваш собственный вход в Claude (подписка, API-ключ или
setup-token). Бинарник Claude Code в установщик всё же попадает — его кладёт
туда платформенный пакет Agent SDK, и это почти весь его размер.

## Что внутри

```
Strategy Desk (Electron + Preact)
   └─ Claude Agent SDK (@anthropic-ai/claude-agent-sdk)
        └─ MCP-сервер tvmcp  (uv --directory <path> run python -m tvmcp)
             └─ TradingView Desktop  (--remote-debugging-port=9223)
```

- **Копилот** — чат с потоковым ответом, строками вызовов инструментов,
  индикатором «думает», кнопкой «Стоп», счётчиком токенов и стоимости,
  режимами «Экономный / Полный».
- **Соединения** — четыре лампочки (TradingView запущен · порт CDP ·
  сервер tvmcp · Claude) и кнопка «Запустить TradingView».
- **Быстрые действия** — четыре готовых запроса («Прочитать мой график» и т.д.).
- **Чаты** — полки (Стратегии, Индикаторы, Мои результаты, Журнал, День IB),
  закреплённые, группировка по датам, поиск, переименование/перенос/удаление.
- **День** — приложение ведёт торговый день само: уровни до открытия,
  календарь, проверка ваших правил риска, сводка журнала и сторож сессии
  (диапазон формируется → закрылся → пробой → подтверждение → снятие уровня).
  Всё это считает CLI tvmcp: пара секунд локального процессора на опрос и
  ноль токенов. Ход модели тратится только на события, которые воркфлоу
  назвал в `askModelOn`, и на кнопки «Спросить вердикт» / «Разобрать день».
  Реплей прошедшего дня не отправляет вопросов модели вовсе.
- **База знаний курса** — материалы курса Smart Money / ICT идут прямо в
  поставке: уроки, гайды, разборы конференций и Q&A, домашние задания, словарь
  терминов и графики к ним. Копилот ищет по ним сам (сервер `gt-database`),
  ссылается на конкретную страницу и открывает нужный скриншот, поэтому
  отвечает языком вашего курса, а не «в целом по рынку». Поиск работает
  офлайн: индекс и модель лежат в папке данных приложения.
- **Воркфлоу** — `workflows/<id>/workflow.yaml` + `prompt.md`: промпт-блок,
  быстрые действия, каталог отчётов и (необязательно) секция `panel` с
  описанием дня. В поставке: «Лаборатория стратегий», «День IB (US500)» и
  «V1B3 на FundingPips». Ни одно число стратегии не живёт в коде.
- **Настройки** — способ входа в Claude, путь к tvmcp, порт CDP, наборы
  инструментов, файл правил риска и файл журнала, воркфлоу по полкам,
  модель и effort, права инструментов, тема, профиль трейдера.
- **Помощь** — схема подключения, три шага, список типичных проблем.

## Требования

Для установленного приложения (сборка макро-обзоров, `build-installer.cmd`):

- Windows 10/11;
- TradingView Desktop (из Microsoft Store или с tradingview.com);
- подписка Claude — вход делается один раз командой `claude` → `/login` в
  терминале; приложение запускает ваш Claude Code и пользуется этим входом;
- свой аккаунт TradingView и его cookie `sessionid` — мастер настройки
  объясняет, где его взять в браузере.

Для сборки из исходников дополнительно: Node.js 22+, npm 10+,
[uv](https://astral.sh/uv) в `PATH` и клон
[tradingview-mcp](https://github.com/Miha21222/tradingview-mcp) (путь
указывается в Настройках — по умолчанию он пуст, установленное приложение несёт
tvmcp с собой).

## Установка

Запустите `Strategy-Desk-<версия>-x64.exe`. Установщик ставит приложение
**только для вашего пользователя**, поэтому не просит прав администратора;
папку установки можно выбрать, ярлык на рабочем столе создаётся. Подписи кода
пока нет — при первом запуске Windows SmartScreen покажет предупреждение
(«Подробнее» → «Выполнить в любом случае»).

Внутри установщика: само приложение, tvmcp с `uv` для сборки его окружения,
родной бинарник Claude Code из Agent SDK, шаблон папки данных
(`vault-template/`: скилл `macro-review`, инструменты и настройки шкалы),
промпты (`prompt/`), воркфлоу и книга правил старой оболочки. **Базы знаний
курса в этой сборке нет** (`SD_BUNDLE_KB=0`): материалы курса не
распространяются, а обзорам дня они не нужны.

### Что делает мастер настройки

Открывается сам при первом запуске, потом живёт в Настройках. Шесть шагов, на
каждом — проверка и кнопка там, где приложение может сделать само:

1. **Папка данных.** Где будут обзоры, журнал и инструменты агента. По
   умолчанию `Документы\Strategy Desk`; «Создать здесь» копирует шаблон из
   поставки. Уже есть vault в Obsidian — выберите его: доложатся только
   недостающие файлы, ваши не трогаются.
2. **Claude.** Проверка входа; команда `claude` → `/login` даётся текстом.
3. **Рынок (tvmcp).** «Развернуть рантайм» ставит Python и зависимости в
   `%APPDATA%\strategy-desk\py` (около 600 МБ, нужен интернет один раз). Этим же
   Python работают инструменты обзора.
4. **TradingView и порт.** «Запустить TradingView» открывает её с портом
   отладки 9223.
5. **Сессия TradingView.** Cookie `sessionid` из браузера: вставить, сохранить
   (шифруется `safeStorage`), «Проверить» — один запрос к tradingview.com.
6. **Расписание.** «Включить расписание» регистрирует в планировщике Windows
   три задачи от вашего имени: обзор перед Европой 09:30, перед Америкой 16:00
   (и 15:00 на неделях разного перевода часов), итог дня 20:00, пн–пт, по
   киевскому времени — мастер показывает часовой пояс компьютера и
   предупреждает, если он не киевский. Cookie при этом записывается в
   переменные окружения пользователя Windows (`TV_SESSIONID`) — иначе задача,
   запущенная планировщиком, его не увидит; «Убрать расписание» удаляет и
   задачи, и переменную. Компьютер должен быть включён и вход в Windows выполнен.

После мастера приложение открывается на «Макро-ревью»; чат обзора — это ваш
Claude Code в папке данных, с сервером `tradingview` из поставки (настройка
«Давать агенту обзора сервер TradingView из поставки», у владельца выключена —
его сервер приходит из `~/.claude`).

**Где лежат данные:** `%APPDATA%\strategy-desk` — `config.json`, `chats.json`,
`profile.json`, `panel.json`, `prompts/`, `transcripts/`, `chat-workspace/`,
`py/` (окружение Python). Секреты (API-ключ, `sessionid`) шифруются через
`safeStorage`. Удаление приложения эту папку **не трогает**: чаты, настройки и
профиль переживут переустановку. Папка данных с обзорами — ваша, где выбрали.

**Обновления (с 0.2.1).** `src/main/updater.ts` поверх `electron-updater`:
приложение само спрашивает GitHub Releases этого репозитория (через 30 с после
старта и раз в 4 часа, выключается в Настройках → Справка), скачивание и
установка — только по нажатию, установка откладывается, пока идёт чат или задача
(установщик не должен подменять `claude.exe`, которым пользуется обзор по
расписанию). Релиз обязан нести рядом с `.exe` файл `release/latest.yml`
(его пишет electron-builder благодаря блоку `publish` в `electron-builder.yml`;
`--publish never` в скриптах не даёт ничего заливать из сборки). Репозиторий
публичный, проверка идёт без токена. Подписи кода по-прежнему
нет: `electron-updater` проверяет sha512 из `latest.yml`, а не подпись.
`DESK_SMOKE=update` в собранной сборке проверяет весь путь до скачивания
(`DESK_UPDATE_PRETEND=0.0.1` заставляет приложение считать себя старым).

### Собрать установщик для другого трейдера

На Windows, в корне репозитория с установленными `node_modules`:

```
build-installer.cmd
```

Это `SD_BUNDLE_KB=0` + `npm run dist`: стейджит tvmcp и `uv`, пустую базу
знаний, шаблон папки данных из vault владельца (`npm run stage:vault`), собирает
и пакует NSIS. Путь к `.exe` печатается в конце; затем
`npm run dist:check -- --rename-project` запускает собранный бинарник и
проверяет, что он нашёл промпты обзора и шаблон папки данных.

## Запуск из исходников

```bash
npm install
npm run dev        # окно приложения с HMR
npm run typecheck  # tsc для main/preload и renderer
npm test           # vitest
npm run build      # сборка в out/
npm run icons      # перерисовать build/icon.png|ico|icns
npm run stage:vault # шаблон папки данных из vault владельца → resources/vault-template (внутри dist)
npm run dist       # установщик → release/Strategy-Desk-<версия>-x64.exe (нужна сеть)
npm run dist:dir   # только распакованная сборка → release/win-unpacked (быстро)
npm run dist:check -- --rename-project   # запустить собранный бинарник и проверить, что он нашёл всё своё
```

## Первый запуск

1. Нажмите «Запустить TradingView» — приложение откроет его с портом отладки 9223
   (9222 обычно занят wmux). Если TradingView уже запущен без флага — закройте
   его полностью и повторите.
2. Дождитесь четырёх зелёных лампочек.
3. Нажмите «Прочитать мой график» или напишите вопрос.

## Дорожная карта

рабочие процессы (стратегия / индикатор / журнал / день IB), вкладка «День».
