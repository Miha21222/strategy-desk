# UI-чек-лист экрана «Обзор дня»: egui против Electron

Nov 25, 2026 · QA · функционал

Проверка этапа 3 ТЗ без «на глаз»: для каждого состояния экрана — что **обязано** быть на экране (точные строки из `src/renderer/i18n/ru.ts` с их ключами и строки из файлов vault) и чего **быть не должно**. Эталон — снимки и тексты старого приложения в `rust/fixtures/reference-ui/` (шаги `steps.json` и `steps-memory.json` над `rust/fixtures/golden/vault`, 26.10.2026 09:40 по Киеву, светлая и тёмная тема).

## Как проверять

1. Для каждого состояния собрать кадр egui в `egui_kittest` с тем же vault и тем же `now` и пройти те же действия.
2. Каждая строка из столбца «Строка» должна находиться в дереве доступности кадра (`query_by_label` / текст виджетов). Строки, помеченные «данные», берутся из файлов дня — их точное значение в `rust/fixtures/reference-ui/<тема>/text.json`, поле `main`.
3. Каждая строка из «Не должно быть» должна **отсутствовать**. Это главная половина для «Сначала человек»: спрятанное нельзя проверить «на глаз».
4. Ключи i18n: egui берёт строки из своей копии словаря (`desk-ui/src/i18n.rs`); ключ здесь — чтобы найти строку, а не требование к имени.
5. Порядок карточек сверяется по полю `cards` в `text.json` (сверху вниз).

Сырых ключей i18n на экране старого приложения нет ни в одном шаге (`rawKeys` пусто) — в egui их тоже быть не должно.

## 9. Где egui обязан отличаться (ТЗ №21)

26.10.2026 — неделя рассинхрона часов (TEST_PLAN §6). Старое приложение пишет время окон константами; Rust берёт их из `desk_core::windows::window_times`. Отличия только здесь:

| Где | Electron (эталон) | egui на 26.10 | Что сделать в словаре egui |
| --- | --- | --- | --- |
| плитка США | «· 16:00» | «· 15:00» | время из `window_times(Us, date).at` |
| вопрос США | «…США (16:30–18:30)?» | «…США (15:30–17:30)?» | `macro.yourReadAsk.us` с параметрами `{open}–{until}` |
| вопрос Европы | «…Европы (10:00–12:00)?» | то же | то же с параметрами (Европа не сдвигается) |
| полоса США без обзора | «…приходит сам в 16:00…» | «…в 15:00…» | `macro.agentIdle.us` с `{at}` |

Любое другое расхождение строки на этих шагах — баг egui.
